# 100万A股系统化交易与资金管理工作台（卡弗模型与A股定制策略体系）

为拥有 100 万元初始资本、追求年化 10%+ 稳健收益、采用日频（盘后检查）操作节奏的独立投资者打造。针对**“用户自带 A 股数据、预留数据接入接口”**以及**“深度适配 A 股市场微观结构与特有运行规律的分析策略”**两大核心诉求，构建集数据适配层、A股专属策略引擎、卡弗波动率定仓、整百手调仓缓冲带于一体的量化工作台。

---

## 用户确认与关键决策

> [!IMPORTANT]
> **已确认的架构与策略定位**：
> - **数据接入层策略**：用户已有 A 股数据。系统在服务端与前端建立规范、清晰的 `AShareDataAdapter` 标准协议与 HTTP/JSON 接入端点，预留外部数据注入通道（支持用户推送、自定义 API URL 或批量 JSON/CSV 载入），并自带高保真样例数据供无缝调试。
> - **A 股专属分析策略体系**：针对 A 股独特的 **T+1 制度、牛短熊长、高波动、结构性行情突出、跌停流动性枯竭** 等特征，重构适配的量化分析与信号策略：
>   1. **多周期 EWMAC 趋势跟踪与动量过滤**（卡弗经典指数移动平均交叉，融合绝对动量避险）；
>   2. **A 股行业与风格相对强弱动量轮动**（适配 A 股突出的板块轮动效应）；
>   3. **红利低波与均值回归估值自适应策略**（适配 A 股长期震荡市与熊市防御）；
>   4. **A 股流动性断崖与非对称止损防护**（解决跌停板无法卖出的极端风险准备金）。
> - **资金与执行参数**：初始 100 万元，年化目标 10%+，目标年化波动率 10%~12%，日频盘后执行，10%~15% 卡弗缓冲带（避免微调过度磨损手续费）。

## 1. A 股数据适配器标准接口设计（用户即插即用）

为方便用户快速无缝接入自己的数据源（如来自 Tushare、AKShare、掘金、聚宽或自建数据库），系统提供全栈标准接口：

### 1.1 服务端数据接入端点 (`server.ts`)
- `POST /api/ashare/ingest`：接收外部推送的批量标的收盘数据（代码、名称、日期、开高低收量、复权因子、流通市值）。
- `GET /api/ashare/instruments`：获取当前注册的所有 A 股标的列表及最新行情快照。
- `GET /api/ashare/bars?code=:code&limit=250`：获取单标的历史 K 线与指标序列。
- `POST /api/ashare/custom-endpoint`：允许用户在界面配置自己本地的数据服务器 URL（如 `http://localhost:8000/api/quotes`），系统代理转发并自动对齐字段。

### 1.2 前端标准数据接口协议 (`src/types/dataAdapter.ts`)
```typescript
export interface AShareBar {
  tradeDate: string;    // YYYY-MM-DD
  open: number;
  high: number;
  low: number;
  close: number;
  volume: number;
  turnover?: number;    // 成交额
  preClose: number;
  limitUp?: number;     // 涨停价
  limitDown?: number;   // 跌停价
}

export interface AShareInstrument {
  code: string;         // 如 600519.SH 或 510300.SH
  name: string;
  category: 'equity' | 'etf' | 'bond_etf' | 'commodity_etf';
  latestPrice: number;
  atr20: number;        // 20日真实波幅
  annualVol20: number;  // 20日年化波动率 (例如 0.22)
  bars: AShareBar[];    // 历史日K线数组
}
```
系统同时内置一键“导入/粘贴自定义 JSON 数据”与“查看接口文档与 cURL 范例”模态窗口，用户无需修改代码即可动态绑定自己的数据源。

## 2. A 股深度适配的系统化分析策略群

针对 A 股市场的独特性，工作台内置四套深度适配的卡弗衍生量化分析策略：

### 策略 1：A 股多周期 EWMAC 趋势动量与绝对动量避险（顺势爆发）
- **A 股痛点**：A 股单边牛市时上涨斜率极陡，但熊市阴跌漫长，简单死守会遭受巨大回撤。
- **策略算法**：
  - 采用卡弗经典 **EWMAC (Exponential Weighted Moving Average Crossover)**，混合短周期 (8/32)、中周期 (16/64)、长周期 (32/128) 三组均线差值；
  - 经标的价格波动率归一化后，映射为 **-20 至 +20 的预测标量（Forecast Scalar）**；
  - **绝对动量硬开关**：当标的处于 250 日（年线）下方且大盘跌破支撑时，强制将预测标量截断至 $\le 0$（空仓或最低防守仓位），彻底规避 A 股 2018、2022 型长熊。

### 策略 2：A 股结构性行业与风格相对强弱轮动（RS Momentum）
- **A 股痛点**：A 股极少出现齐涨齐跌的普涨，长期呈现剧烈的行业/风格结构分化（如红利高股息 vs 科技AI vs 消费白酒交替走强）。
- **策略算法**：
  - 计算标的池中各标的相对沪深300（或中证全指）的 **20日超额收益率 $\alpha_{20}$** 与 **60日超额收益率 $\alpha_{60}$**；
  - 结合波动率惩罚，计算风险调整动量分（Risk-adjusted Momentum Score）；
  - 动态优选排名前 20%~30% 的强势主线标的，分配更高风险预算权重（Asset Weight Budget）。

### 策略 3：红利低波与均值回归自适应估值（震荡市底仓）
- **A 股痛点**：A 股约 70% 的时间处于宽幅震荡或结构性弱市，追高极易被套。
- **策略算法**：
  - 选取低估值、高股息、低贝塔标的（如红利低波 512890 等）；
  - 结合 20 日布林带或历史波动率分位数，在市场非理性杀跌至极端低位时，自适应扩大波动率倒数安全仓位，提供平稳现金流与心理底仓。

### 策略 4：T+1 流动性断崖与极端跌停风控机制
- **A 股痛点**：A 股实行 T+1，当日买入无法卖出；若遇黑天鹅个股一字跌停将完全失去流动性。
- **策略算法**：
  - **流动性折价惩罚**：换手率异常缩量或接近跌停阈值时，自动预警并冻结追加买入；
  - **集中度硬上限**：单只个股风险敞口不超过总资产的 10%，单只 ETF 不超过 25%，确保任何单标的极端下跌对总资金冲击被严格限制在 1%~2%（符合范·撒普破产防线）。

## 3. 罗伯特·卡弗波动率定仓与 A 股整手计算引擎

### 3.1 资金参数与定仓数学
针对用户 **100 万元资金** 与 **目标年化波动率 12%**：
1. **每日现金波动率预算**：
   $$\text{Daily Cash Vol Target} = \frac{1,000,000 \times 12\%}{\sqrt{250}} \approx 7,589 \text{ 元/天}$$
2. **单标的基准持仓（Vol Sizing）**：
   $$\text{Base Position} = \frac{\text{Daily Cash Vol Target} \times \text{标的权重预算}}{\text{标的日价格波动率 (ATR 或 Price } \times \sigma_{\text{daily}})}$$
3. **结合 A 股预测标量（Forecast Scaler）**：
   $$\text{Target Capital} = \text{Base Position} \times \text{标的现价} \times \left( \frac{\text{Forecast Scalar}}{10} \right)$$
4. **A 股 100 股（1手）整数化规则**：
   $$\text{Target Shares} = \left\lfloor \frac{\text{Target Capital} / \text{Price}}{100} \right\rfloor \times 100$$
5. **卡弗缓冲带判定（Carver Buffer Band，默认 12%）**：
   - 设当前持股为 $S_{\text{current}}$，目标持股为 $S_{\text{target}}$；
   - 若 $|S_{\text{target}} - S_{\text{current}}| \le S_{\text{target}} \times 12\%$，判定为 `BUFFER_HOLD`（不调仓，省去佣金）；
   - 若超出缓冲带，生成明确的整百股买入/卖出委托指令。

## 4. 用户界面与交互流程（专业金融工作台）

### 4.1 布局与模块组织
- **顶部 HeaderBar**：
  - 品牌区：`SYSTEMATIC WORKBENCH` · A股量化版；
  - 快捷切换：[波动率定仓工作台] · [A股策略与指标] · [调仓指令单] · [回测沙盘] · [数据接口与管理]；
  - 资产状态栏：总资金 1,000,000 元 · 目标年化波动率 12% · 现仓比率 · 今日调仓数量。
- **模块 1：数据接口管理中心（Data Adapter Console）**：
  - 实时显示当前数据源连接状态（内置高保真 A 股数据集 / 用户外部接口直连）；
  - 提供数据接口规范文档、cURL 推送测试代码、JSON 批量粘贴导入与导出。
- **模块 2：A 股策略分析与标的评分看板**：
  - 标的池列表：支持 A 股股票与 ETF，展示现价、ATR、20日年化波动率、EWMAC 动量分、相对强弱排名；
  - 策略信号诊断卡：展示当前 EWMAC 三组均线差值、绝对动量开关状态（防熊市）与综合预测标量（-20~+20）。
- **模块 3：卡弗波动率定仓计算台**：
  - 100万总资产与各标的风险平价权重调节滑块；
  - 实时输出每个标的的“波动率比例因子”、“理论仓位金额”、“目标股数（百股整手）”；
  - 风险贡献度分解饼图（保证各标的风险真正平价，高波动标的不喧宾夺主）。
- **模块 4：日频调仓执行清单（带缓冲带标识）**：
  - 标明哪些标的触发买入/卖出，哪些被缓冲带过滤保留；
  - 一键复制交易指令（例如：“600519 买入 100股 / 510300 保持不变 (缓冲内) / 518880 卖出 200股”），方便次日开盘 1 分钟敲单。
- **模块 5：回测与压力测试沙盘**：
  - 仿真 A 股历史典型周期（2018 单边熊市、2019-2020 牛市、2021-2024 结构市），对比卡弗波动率定仓 vs 买入持有 vs 等权重的净值与最大回撤表现。

3. **资金与风险模型严密**：精确还原罗伯特·卡弗的目标波动率倒数定仓与缓冲带节约换手损耗逻辑。
