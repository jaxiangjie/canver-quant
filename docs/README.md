## 核心设计理念

1. **波动率定仓，而非均值方差过拟合**：
   传统 Markowitz 均值-方差模型极易对历史收益率过拟合（“敏感性爆炸”），且在 A 股共振暴跌时协方差矩阵求逆失真。系统严格遵循卡弗框架，仅以**波动率与现金风险预算（Cash Volatility Target）**进行基础定仓，将风险控制置于收益预测之前。

2. **解决“年化偏低”的阿喀琉斯之踵 —— IDM 分散化乘数**：
   在多资产低相关组合中，波动率会被天然平抑。系统引入卡弗公式精确计算 $IDM$（通常在 $1.3 \sim 1.8$），对各资产仓位进行波动率补偿，在不突破组合总杠杆硬顶（$\le 20\%$）的前提下，将组合实际波动率锚定在目标区间，实现年化收益跃升至 $10\% \sim 14\%+$。

3. **零频繁换手，严守 Buffer 死区缓冲带**：
   A 股的高频调仓会产生巨大的佣金滑点磨损。系统设置 $10\% \sim 15\%$ 的死区缓冲带（Buffer Band），偏离未达阈值坚决不调仓，实现**业余投资者每日收盘仅需 5 分钟**的极简实盘落地。

4. **严格适配 A 股监管与交易规则**：
   所有调仓单强制执行**一手 100 股向下取整**；ETF 享受免印花税率；针对不可做空、T+1、涨跌停流动性断裂设计了 ADV 调仓上限保护与单边防守机制。
