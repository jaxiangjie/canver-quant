## 2. 核心模块与职责划分

### 2.1 波动率定仓引擎 (`carverEngine.ts`)
* **现金波动率目标计算**：
  $$\text{Daily Cash Vol Target} = \frac{\text{Total Capital} \times \sigma_{\text{target}}}{\sqrt{250}}$$
* **单股价格波动率**：
  $$\text{Instrument Daily Vol} = P_t \times \frac{\sigma_{\text{ann}}}{\sqrt{250}}$$
* **IDM 分散化乘数与仓位预算放大**：
  $$\text{Base Position} = \frac{\text{Daily Cash Vol Target} \times w_{\text{budget}} \times \text{IDM}}{\text{Instrument Daily Vol}}$$
* **杠杆硬顶约束机制**：
  当全组合加权目标总持仓资金超过 $(1 + \text{Max Leverage}) \times \text{Total Capital}$（例如 120 万元）时，启动全局线性收缩（Pro-Rata Scaling），保证绝不超额杠杆。
* **一手 100 股向下整取**：
  $$\text{Target Shares} = \lfloor \frac{\text{Raw Shares}}{100} \rfloor \times 100$$
* **Buffer 死区缓冲带判定**：
  $$\text{Deviation Ratio} = \frac{|\text{Target Shares} - \text{Current Shares}|}{\text{Target Shares}}$$
  若 $\le \text{Buffer Threshold}$（默认 $12\%$），判定为 `HOLD`，不产生交易动作与滑点磨损。

### 2.2 相关性分析与 IDM 计算引擎 (`correlationEngine.ts`)
* **对数日收益率提取**：$r_t = \ln(P_t / P_{t-1})$；
* **滚动 60 个交易日皮尔逊相关系数矩阵**：
  $$r_{xy} = \frac{\sum (x - \bar{x})(y - \bar{y})}{\sqrt{\sum (x - \bar{x})^2 \sum (y - \bar{y})^2}}$$
* **组合有效分散化乘数计算**：
  $$\text{IDM} = \frac{1}{\sqrt{\frac{1}{N} + \left(1 - \frac{1}{N}\right) \bar{\rho}}}$$

### 2.3 策略信号与战术偏置 (`ashareStrategies.ts`)
* **多周期 EWMAC 信号**：8/32、16/64、32/128 日指数移动平均差值，映射为 $[-20, +20]$ 卡弗预测标量；
* **绝对动量过滤器**：收盘价站上 250 日年线，过滤 A 股长期单边下行行情；
* **股债性价比 ERP 偏置**：$\text{ERP} = \frac{1}{\text{PE}} - r_{10Y}$。当 ERP 位于历史 $80\%$ 高分位时，赋予权益资产 $1.15\times$ 的逆向安全边际进攻偏置。

## 4. 健壮性与异常边界设计

1. **零分母与低价格防御**：所有除数（价格、日波动率、历史成交量）均包裹 $\max(\epsilon, \dots)$ 机制，杜绝 `NaN` 或 `Infinity`。
2. **极端流动性受阻**：在涨停跌停或成交额低于阈值（ADV Limit）时，系统降级为分日逐步调仓模拟，防止模拟净值失真。
3. **数据隔离与容灾**：支持一键切换真实外部 API 与内置合成耦合数据源，断网环境或 API 欠费下系统无缝自愈。
